## 🧠 Áreas de Enfoque y Proyectos Destacados

### 1. IA Aplicada a la Salud y Biomecánica (HealthTech)
*   **Visión Computacional Pulmonar:** Investigación y desarrollo de clasificadores de patologías torácicas utilizando PyTorch y *Swin Transformers* sobre imágenes de tomografías computarizadas, operando a través de túneles SSH hacia Google Colab.
*   **Análisis Biomecánico:** Evaluación de posturas corporales mediante arquitecturas de redes neuronales recurrentes (LSTM) en PyTorch, optimizando hiperparámetros como *dropout* y *early stopping* para maximizar la precisión en series temporales.

### 2. Procesamiento de Lenguaje Natural (RAG y Chatbots)
*   **DocuMind_AI:** Sistema corporativo de Generación Aumentada por Recuperación (RAG) utilizando bases de datos vectoriales FAISS, orquestación con LangChain y despliegue de interfaces a través de FastAPI.
*   **Asistente Conversacional Vectorial:** Canalización de datos estructurados para retención de contexto utilizando la base de datos Qdrant en contenedores Docker y la API de OpenAI.

### 3. Minería de Datos, Audio y Optimización Operativa
*   **Detección de Fraude en Transacciones:** Propuestas de minería de datos sobre conjuntos de 100,000 registros y 43 variables del corpus de Kaggle.
*   **Síntesis de Audio y MIDI:** Generador de audio de aprendizaje profundo y reproductor MIDI interactivo con PyTorch, FluidSynth y midi2audio.
*   **Ingeniería de Procesos:** Automatización de flujos de trabajo administrativos (formas documentales institucionales) mediante *openpyxl*, y algoritmos predictivos para la optimización de puntos de reorden de inventarios.
